# Card Caller

Local web app that draws random cards from a 52-card deck (no repeats until shuffle).

## Run

Open `index.html` in a browser (double-click, or `open index.html`). No install or internet needed.

## Controls

- **Show card** — display the drawn card face
- **Speak card** — read the card name aloud
- **Draw card** — next card from the remaining deck
- **Shuffle / Reset** — reshuffle the full deck

You can use show, speak, or both.
