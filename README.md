# Card Caller

Simple local web app that draws a random card from a standard 52-card deck (no duplicates until you shuffle). Cards use classic French-pattern artwork, including real Jack / Queen / King faces.

## How to run

Open `index.html` in any modern browser:

- **Mac:** double-click the file, or run `open index.html` from this folder
- **Windows:** double-click the file, or right-click → Open with → your browser
- **Linux:** double-click, or run `xdg-open index.html`

No install or server required. Keep the `cards/` folder next to `index.html`.

## Controls

- **Draw card** — show the next random card from the remaining deck
- **Shuffle / Reset** — reshuffle the full deck and clear the current card
